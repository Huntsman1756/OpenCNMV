## Update transition vocabulary (G2-D, closed set)

```text
NO_CHANGE                        replay / identical re-observation
NEW_FILING                       filing not present in base
NEW_FILING_VERSION               new version_seq on existing filing
NEW_SUBMISSION_VARIANT           new variant_id on existing filing
NEW_VARIANT_VERSION              new variant_version (supersedes-linked)
NEW_VERSION_EVENT                version_event recorded
VARIANT_SCOPED_VERSION_EVENT     event affects a variant subset
FILING_SCOPE_NOT_OBSERVABLE      event exists, scope unobservable
ARTIFACT_CHANGED                 artifact set differs under a new version
ARTIFACT_ADDED                   artifact added to an existing owner
ARTIFACT_REMOVED                 removal claimed w/ REMOVED_CONFIRMED
                                 evidence (row retained — ledger semantics)
FACT_ADDED / FACT_REMOVED        fact set differs across versions
FACT_PAYLOAD_CHANGED             same structural identity, new payload
EXTENSION_MAPPING_ADDED          new mapping records
EXTENSION_MAPPING_CHANGED        verdict/analysis fields legitimately
                                 updated (PROVEN-only rewrites_identity
                                 is recomputed, never trusted)
VIEW_RESOLUTION_RECORDED         new UI-language resolution row
SOURCE_STATE_CONFLICT            same identity, conflicting content —
                                 never applied
UNRESOLVED                       evidence insufficient — never applied
```

CLI/API only after G2-C.
